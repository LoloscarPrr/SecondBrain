# SecondBrain specs

Specs are the implementation contract for product and technical changes.

Lifecycle: `DRAFT → LOCKED → IMPLEMENTING → VERIFYING → DONE`.

Naming: `SB-<AREA>-NNN-short-title.md`.

Common areas:
- `CORE` architecture/build/release
- `MEM` memory engine
- `TIME` temporal engine
- `IMG` image/OCR
- `UI` interface/adaptive layouts
- `AI` model/retrieval/agent work
- `PRIV` privacy/security

Every spec must define observable acceptance criteria and record verification results before DONE.
